# Project overview

**Nincsenek Fények!** explores playful fact-checking for different age groups — making verification engaging rather than dry.

## Goals

- Present fact-checking in a format that works across generations.
- Combine content, application flows, and background processing in a deployable stack.
- Iterate in the open on **product direction** here; source code stays in a private repository.

## Technical direction (high level)

- API-driven backend with async jobs for longer-running tasks.
- Container-based deployment for repeatable environments.
- Frontend and content layers evolve with the format.

## Documentation in this repo

This public repository holds **summaries and orientation** only. It does not include API keys, deployment credentials, or application source.

See the root [README](../README.md) for collaboration.
