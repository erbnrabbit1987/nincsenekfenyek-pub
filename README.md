# Nincsenek Fények! — public overview

**Nincsenek Fények!** is an application initiative around **playful fact-checking “for young and old”** — making verification and curiosity accessible through a format meant to be tried, not only read about.

> **This repository contains documentation and project summary only.** Application source code is **not** published here.

---

## Direction

- **Content & format** — fact-check experiences that work across age groups without feeling like homework.
- **Application layer** — API-driven flows, background jobs, and containerised deployment (details live in the private codebase).
- **Own initiative** — built to serve the project’s format, not as outsourced client product work.

---

## Stack (high level)

Python · FastAPI · async / worker jobs · Docker · data stores as required by the current prototype (evolving).
